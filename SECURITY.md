# Security Policy

## Reporting A Vulnerability

Please report suspected vulnerabilities privately to the SPS institutional
security contact for the Government Payments Project.

Do not create public issues for vulnerabilities, credentials, production data,
or payment-network integration details.

## Supported Versions

Security support applies to the active main branch and any release branches
that SPS designates for production or UAT operation.

## Handling Expectations

SPS should acknowledge reports, triage severity, coordinate fixes with affected
operators, and publish advisories when disclosure is appropriate. Vulnerability
handling must protect payment data, secrets, certificates, bank identifiers, and
Revenue Authority integration details.
